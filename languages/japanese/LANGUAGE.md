# Japanese (日本語) — teaching notes

- **Folder:** `languages/japanese` · **TTS tag:** `ja-JP`
- **Levels:** CEFR **and** JLPT — rough equivalence N5 ≈ A1, N4 ≈ A2, N3 ≈ B1, N2 ≈ B2, N1 ≈ C1. Record both in `plan.md` milestones.

## Script & typing
- Hiragana, katakana, kanji. **Romaji only as a crutch** until kana are solid, then drop it.
- **Furigana:** give the reading in full-width parentheses after any kanji word the learner hasn't learnt: 食べる（たべる）.
  Kanji they know (mastery ≥ 3 in `vocabulary.md`) appear without readings.
- Phone: Japanese keyboard (romaji or kana input → convert). Accept kana-only answers for words not yet learnt in kanji;
  romaji answers only until the learner has a Japanese keyboard.
- Register: teach です/ます first; plain form from ~A2; mark register (casual / polite / keigo) when it matters.

## Notation in files
- Japanese column = the word as normally written; Reading column = kana.
- Verbs: group (u-verb / ru-verb / irregular), ます-form, て-form. Adjectives: い / な. Nouns: counter if relevant.
- Example sentence: Japanese, then " — " English gloss.
- Vocabulary columns: Japanese | Reading (kana) | English | Grammar info | Example sentence | First learned | Last reviewed | Mastery.

## Onboarding questions
1. Hiragana / katakana: none, some, solid? Roughly how many kanji?
2. Background (classes, anime/self-study, JLPT taken?) and goal (travel, media, JLPT level?).
3. Want romaji alongside kana for now?

## Grammar map (A1/N5 → B2/N2)
- **A1 / N5:** kana; です; particles は が を に で へ と も の; ます-form present/past/negative; い / な adjectives; こそあど;
  numbers & counters; あります / います; ～たい; ～てください.
- **A2 / N4:** て-form uses (～ている, ～てもいい, ～てはいけない), plain form, ～たことがある, potential, volitional, ～と思う,
  conditionals (～たら, ～ば, ～と), giving/receiving (あげる / くれる / もらう), comparisons.
- **B1 / N3:** passive, causative, causative-passive, ～ようだ / ～そうだ / ～らしい, ～ため / ～ように, noun modification (relative clauses),
  keigo basics (尊敬語 / 謙譲語).
- **B2 / N2:** advanced keigo, written style (である), patterns like ～わけ, ～はず, ～にもかかわらず, ～ばかり; nuance particles.

## Pitfalls
- は vs が; に vs で (place of existence vs action); transitive/intransitive pairs (開ける / 開く); counters; keigo;
  kanji readings (on / kun); long vowels & double consonants (おばさん / おばあさん, きて / きって); pitch accent (optional).
