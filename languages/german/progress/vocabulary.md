# Vocabulary

Nouns: ALWAYS article + plural (der Tisch, -e; das Haus, ¨-er). Verbs: Präteritum + Partizip II if irregular, separable prefix (an|rufen), haben/sein, case government (helfen + Dat). Prepositions: case. Always add an example sentence.
